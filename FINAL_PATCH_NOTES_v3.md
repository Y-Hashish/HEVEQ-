# HEVEQ Final Patch v3

## Fixes added on top of v2

1. Email confirmation flow
- Added frontend route: `/auth/confirm-email`.
- Registration now redirects to the email confirmation page after successful account creation.
- Email confirmation links generated by the backend now open a real frontend page instead of falling back to the home page.
- Added resend confirmation email UI and wiring to `POST /api/Auth/resend-confirmation-email`.
- Added frontend call to `POST /api/Auth/confirm-email`.
- Login now redirects users who still need email confirmation to the confirmation page.

2. Marketplace order escrow error
- Fixed backend `GET /api/marketplace-orders/{id}/escrow` so it no longer throws `Entity EscrowRecord ... was not found` for orders still in `PendingPayment`.
- If the escrow record has not been created yet, the endpoint now returns a safe pending-payment escrow DTO.
- Frontend marketplace payment and marketplace orders pages now treat escrow as optional, so pending-payment orders do not break the page.

3. Marketplace orders UI
- Reworked `/marketplace-orders` to follow the same layout and styling pattern as `/bookings`.
- Added consistent list/details layout, status badges, summary cards, timeline, escrow section, actions section, cancellation, and dispute panels.
- Pending payment now displays normally with a payment action instead of breaking the page.

## Build verification

Frontend build was verified successfully:

```bash
cd Frontend
npm install --no-audit --no-fund
npm run build
```

Backend build could not be verified in this environment because `.NET SDK` is not installed here. Please verify locally:

```bash
cd Backend
dotnet build HEVEQ.Api/HEVEQ.Api.csproj
dotnet ef database update --project HEVEQ.Infrastructure --startup-project HEVEQ.Api
dotnet run --project HEVEQ.Api
```
